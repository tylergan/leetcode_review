Trie Fundamentals

Core idea: Each edge represents one character. Walking from the root through characters answers prefix questions in O(length of query).

Insert: curr = root for each char in word: create child if missing curr = child curr.end = true Search exact word: walk every char return finalNode.end

Important:

A prefix is not automatically a word. The end marker is what distinguishes "app" after inserting "apple".

Design Add and Search Word

O(m) normal search / O(26^d * m) with d dots

Goal: Support adding words and searching patterns where . can match any single letter.

Mental Note: Let DFS Own the Search

The tempting overcomplication is to count consecutive dots, look ahead to a future target character, and try to jump there. That creates edge cases: dots at the start, dots at the end, missing-length checks, and discarded recursive results.

Instead, make the whole search recursive: dfs(node, word, i): if node == nil: return false if i == len(word): return node.end if word[i] == '.': try every child with dfs(child, word, i+1) return true if any child works return dfs(node.children[word[i]], word, i+1)

Why No Target Character Is Needed

Searching ".ay" after adding day, bay, may: root ├── d → a → y (end) ├── b → a → y (end) └── m → a → y (end) At i=0, '.' means try d, b, and m. Each recursive call naturally moves to i=1, where the next character is 'a'. The future target is handled by the next recursive frame.

Key Pitfall

If the remaining pattern is all dots, do NOT return true immediately. Example: added: "b" search: "b.." The prefix exists, but no word of length 3 exists. The base case must still land on a node with end == true.

Word Search II

O(m * n * 4^L) worst case / Trie pruning in practice

Goal: Find all dictionary words that can be formed by walking horizontally or vertically through the board without reusing a cell in the same word.

Trie + Board DFS

1. Build a trie from all words. 2. Start DFS from every board cell. 3. At each cell: - Check whether the current trie node has board[i][j]. - If not, prune immediately. - If the child has a complete word, record it. - Mark board[i][j] as visited. - Explore four directions. - Restore board[i][j].

Why Store the Word on the Terminal Node?

Instead of rebuilding the path string on every DFS step, store the full word at the terminal trie node: curr.word = word Then when DFS reaches that node: res = append(res, curr.word) curr.word = "" // prevents duplicate output

Mental note:

The trie is the pruning structure. If the current board path is not a prefix in the trie, stop immediately instead of continuing to build paths that cannot match any target word.
