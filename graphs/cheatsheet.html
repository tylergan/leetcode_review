Clone Graph

O(V + E) Time / O(V) Space

Goal: Return a deep copy of a connected undirected graph.

BFS With Original-to-Clone Map

if node == nil: return nil clones[node] = new Node(node.val) queue = [node] while queue is not empty: curr = pop queue for neighbour in curr.neighbours: if neighbour is not cloned: clones[neighbour] = new Node(neighbour.val) push neighbour clones[curr].neighbours append clones[neighbour]

Key Insight

The map answers two questions: 1. Have we already discovered this original node? 2. What clone should edges point to? Never append original neighbours into the clone. Every edge in the cloned graph must point to cloned nodes.

Number of Islands

O(m * n) Time / O(m * n) Space worst case

Goal: Count connected components of land in a 2D grid. Connections are horizontal and vertical only.

Sink Land DFS

for each cell: if cell is water: continue count++ dfs(cell) dfs(row, col): if out of bounds: return if cell is water: return mark cell as water dfs(up) dfs(down) dfs(left) dfs(right)

Key Insight

The first land cell found in an island increments count. DFS then "sinks" every connected land cell by changing it from '1' to '0'. That prevents the rest of the same island from being counted again later in the outer loop.

Max Area of Island

O(m * n) Time / O(m * n) Space worst case

Goal: Find the largest connected component of land. Area is the number of cells in the island.

Same DFS, Different Accumulator

for each land cell: currArea = 0 dfs(cell) maxArea = max(maxArea, currArea) dfs(row, col): if out of bounds or water: return currArea++ mark cell as water dfs(up/down/left/right)

Key Difference from Number of Islands

Number of Islands: count how many times we start DFS from fresh land Max Area of Island: count how many cells one DFS sinks keep the largest DFS size seen
